# 🤖 Simple Rule-Based Chatbot

A basic console chatbot that responds to predefined greetings and commands, built as part of the **CodeAlpha Python Programming Internship** (Task 4).

## 📌 Overview

This chatbot uses simple rule-based logic to recognize specific user inputs (like "hello", "how are you", and "bye") and reply with predefined responses. It runs in a continuous loop until the user chooses to exit.

## ✨ Features

- Responds to greetings, farewells, and basic questions
- Case-insensitive input matching
- Provides a fallback response for unrecognized input
- Runs continuously until the user says a farewell keyword
- Handles empty input gracefully

## 🛠️ Concepts Used

- `if-elif` conditional chains for rule-based matching
- Functions for separating response logic from the chat loop
- `while` loop for continuous conversation flow
- Input/output handling

## 🚀 How to Run

1. Make sure Python 3 is installed on your system.
2. Clone this repository or download the script.
3. Run the following command in your terminal:

   python simple_chatbot.py

4. Type messages like "hello", "how are you", or "bye" to interact with the bot.
5. Type "bye", "goodbye", "exit", or "quit" to end the conversation.

## 📷 Sample Conversation

========================================
   SIMPLE RULE-BASED CHATBOT
========================================
Type 'bye' to end the conversation.

You: hello
Bot: Hi there! How can I help you today?
You: how are you
Bot: I'm fine, thanks! How about you?
You: bye
